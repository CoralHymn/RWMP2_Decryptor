## 介绍
  - RWMP2_Decryptor是“Rusted Warfare”游戏的MOD加密工具“RWMP2”的解锁工具
  - 此版本使用python制作，无giu功能

## 1.安装（windows）

下载完成后双击exe文件即可开始安装 \
现在选择您的更新目录，默认安装到c盘根目录下 \
（您可以修改到其他位置，但请注意，如果放到软件文件夹例如“Program Files”内安装，请运行时使用”管理员运行“） \
现在安装好了桌面上会出现“RWMP2_Decryptor”的快捷方式 \
若没有快捷方式，请去您的安装目录下寻找“RWMP2_Decryptor.exe”文件 

## 2.使用

双击桌面快捷方式即可打开，会弹出终端： 
```bash
琴海奶油版权所属，请勿用于商业用途！
目前版本为 Alpha2.x.x
查看教程前往官网：https://coralhymn.com
请输入要修复的ZIP文件路径:
  ```
若是没有以上信息，很可能是安装失败，重新安装即可 

在开始使用前请把“rwmod”文件改名成“zip”文件 \
现在您有两种使用方法 


#### 1.
  - 输入或拷贝您的zip文件目录位置
  - 随后按下回车键即可
  - 精确到文件，从*盘根目录开始输入

#### 2.（推荐）
  - 直接拖动您的文件到打开的终端里面（会自动填写您的文件位置）
  - 随后按下回车键即可

## 3.文件位置

由于Alpha2.0.*版本含有缺陷，最终输出的文件可能在模组文件目录下，也有可能在软件目录下（请右击桌面图标，点击”打开文件所在的位置”）\
这时你可以看见一个后面为“最终修复”的zip文件，这里面就是解锁出来的文件了

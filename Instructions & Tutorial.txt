Quick Guide  
1. Open the .exe file.  
2. Rename the mod file to .zip, then drag and drop it into the program and press Enter.  
Note: The current version (Alpha 2.0.2) has a bug—the final output file may appear either in the mod file directory or the software directory (right-click the desktop icon and select "Open file location" to check).

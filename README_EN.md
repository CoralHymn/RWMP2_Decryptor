## Introduction
  - RWMP2_Decryptor is a decryption tool for the MOD encryption utility "RWMP2" used in the game "Rusted Warfare"
  - This version is developed using Python and does not include GUI functionality

## 1. Installation (Windows)

After downloading, double-click the exe file to begin installation \
Now select your installation directory, which defaults to the root of C drive \
(You can modify this to other locations, but please note that if installed in program folders like "Program Files", you'll need to "Run as Administrator") \
After installation completes, a "RWMP2_Decryptor" shortcut will appear on your desktop \
If no shortcut appears, please look for the "RWMP2_Decryptor.exe" file in your installation directory

## 2. Usage

Double-click the desktop shortcut to launch, which will open a terminal:
```bash
Copyright belongs to QinHai Cream, not for commercial use!
Current version is Alpha2.x.x
Visit official website for tutorial: https://coralhymn.com
Please enter the ZIP file path to repair:
  ```
If you don't see this information, the installation likely failed and you should reinstall

Before starting, please rename "rwmod" files to "zip" files \
Now you have two usage methods

#### Method 1:
  - Input or paste your ZIP file directory path
  - Then press Enter
  - Must specify exact file path starting from *drive root

#### Method 2: (Recommended)
  - Simply drag your file into the opened terminal (this will auto-fill the file path)
  - Then press Enter

## 3. File Location

Due to defects in Alpha2.0.* versions, the output file may be in either the mod file directory or the software directory (right-click desktop icon and select "Open file location") \
You'll see a ZIP file with "Final Repair" suffix - this contains the decrypted files
